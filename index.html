FAQ

Frequently Asked Questions

Everything you need to know about TaskFlow.

Is TaskFlow really free?
Yes! TaskFlow is completely free to use. All core features including AI task management, offline support, 10+ themes, Kanban board, calendar, and analytics are available at no cost.
Do I need a Groq API key to use AI features?
A Groq API key is required to use AI-powered features like task generation, priority suggestions, and daily briefings. You can get a free API key at console.groq.com. All other features work without it.
Does TaskFlow work offline?
Absolutely. TaskFlow is built offline-first using a service worker and local IndexedDB storage. You can create, edit, and complete tasks without internet. Everything syncs automatically when you reconnect.
How is my data stored?
Your tasks and profile are securely stored in Supabase (PostgreSQL), a trusted cloud database. Data is encrypted at rest and in transit. We never sell your data to third parties.
Can I export my tasks?
Yes! Go to Settings → Data → Export JSON to download all your tasks and projects as a JSON file at any time.
Can I sign in with Google?
Yes. TaskFlow supports Google OAuth for quick sign-in. You can also create a traditional account with email and password.
