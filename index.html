FAQ

Questions? Answered.

Everything you need to know about TaskFlow.

Is TaskFlow really free to use?
Yes! TaskFlow's core features — unlimited tasks, all view modes, AI assistance, offline sync, and 5 themes — are completely free. We'll introduce optional premium tiers for teams and power users in the future.
How does offline mode work?
TaskFlow is built as a Progressive Web App with a service worker that caches all app assets and a local-first database. All changes are stored locally and synced to the cloud when connectivity returns. You'll never lose data.
What AI model powers TaskFlow?
TaskFlow uses Groq's ultra-fast inference API with the latest open-source models. You can optionally bring your own API key for higher usage limits or use a different model provider.
Can I install TaskFlow as an app?
Absolutely! TaskFlow is a full Progressive Web App. On mobile, tap "Add to Home Screen" in your browser, and on desktop you'll see an install icon in your address bar. It works just like a native app.
Is my data secure and private?
Your tasks are stored in your own Supabase database, protected by row-level security policies. We never sell your data. All AI queries are sent directly from your browser to the AI provider — we don't store AI conversations.
